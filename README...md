# Student Management System

## About the Project
The Student Management System is a Python-based application that helps manage student information and academic performance.

## Features
- Add new students
- View student performance reports
- Update student information
- Record subject-wise marks
- Calculate total marks, percentage, and grade
- Calculate attendance percentage
- Validate duplicate roll numbers, marks, and attendance
- Save and load student records using a JSON file

## Technologies Used
- Python
- JSON
- Git and GitHub

## Requirements
- Python 3 installed
- Visual Studio Code (recommended)

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   ```bash
   python students.py
   ```

## Usage
Follow the menu displayed in the terminal to add students, view performance reports, update records, or exit the application.

## Data Storage
Student records are stored in `students.json`. The application loads saved records when it starts.
